Independent Build

AI Voice Receptionist

A voice AI system built to handle inbound calls and messages for a dental clinic — greeting callers, extracting appointment details from natural conversation, and writing confirmed bookings straight to the calendar.

The Problem

What needed solving

A clinic with no after-hours coverage loses patients silently. Calls go unanswered in the evening and at weekends, and the caller books somewhere else.

Reception staff also lose time each morning working through voicemails and transferring appointment requests into the calendar by hand.

This build set out to answer a specific question: could a voice agent handle the full intake conversation well enough that no call goes unanswered and nothing needs re-typing?

The Build

How the system works

  1. Voice intake through Vapi

    Vapi receives inbound calls and messages. The agent greets the caller, then asks for their name, preferred appointment time, and reason for visiting.

  2. Extract structure from conversation

    The call transcript goes to the OpenAI API, which pulls structured data — name, contact number, requested date and time, appointment type — out of ordinary spoken language.

  3. Route through n8n

    n8n receives the structured data, validates it, and decides what happens next. If the requested slot is open it confirms; if not it offers alternatives.

  4. Sync and notify

    Confirmed bookings are written to Google Calendar in real time, and a formatted Slack message alerts the clinic team with the full details attached.

Stack

Tools used

n8n Vapi (Voice AI) OpenAI API Google Calendar API Slack API Google Sheets
Outcome

What the system delivers

The system handles inbound calls at any hour, including evenings, weekends and holidays.

Appointment details move from conversation to calendar without anyone re-typing them.

The full intake path — from first contact through confirmed booking to staff notification — runs end to end without a manual step.
